# MathLens

本地优先的考研数学一试卷诊断与针对性复测工具。

第一版围绕一个最小闭环：

```text
导入已完成试卷 → 逐题诊断 → 从本地题库检索 → 针对性小测 → 更新个人画像
```

## 启动

需要 Python 3.11+。运行时由 Python 本地服务提供 API 和静态文件；前端源码位于 `web/`，使用 React + TypeScript + Vite 构建。

普通使用不需要安装 Node.js：

```bash
python server.py
```

浏览器打开 `http://127.0.0.1:4173/`。

Windows 用户可以直接双击项目根目录的 `start_mathlens.bat`，脚本会启动服务并自动打开浏览器。关闭名为 `MathLens Server` 的命令行窗口即可停止服务。

如果浏览器没有自动打开，请手动访问 `http://127.0.0.1:4173/`，并保持 `MathLens Server` 窗口不要关闭。

首次启动会在 `.mathlens/` 中创建 SQLite 数据库和示例数据。真实资料放在 `.mathlens/`，不会进入 Git。

## 前端开发

需要修改前端时，在另一个终端运行：

```bash
cd web
npm install
npm run dev
```

Vite 开发服务器默认使用 `http://127.0.0.1:5173/`，并将 `/api` 请求代理到本地 Python 服务 `http://127.0.0.1:4173/`。提交或交付前运行 `npm run build`，构建结果会写入根目录 `dist/`，双击 `start_mathlens.bat` 仍然直接启动生产构建。

## 当前能力

- 导入已完成试卷 PDF，并保存原始文件到本地待确认队列
- 当前题目确认保留了手工兜底入口；OCR、版面切题和题目截图关联是下一阶段的接入点，尚未伪装成已完成能力
- 试卷、题目、错因、解题环节和复测记录
- 本地题库检索和筛选
- 针对单题建立 3～5 题的检验小测
- 记录正确率、用时、自信程度和重复错误
- 用证据更新个人画像：未验证、不稳定、基本掌握、迁移通过
- 导入自有题库 JSON

在“本地题库”页可以直接导入 `questions.json`；兼容 `stem`、`content`、`question`、`tags`、`keywords`、`chapter` 等常见字段。

## PDF 解析与 OCR

上传 PDF 后，系统会自动调用本地解析接口：

1. 对有文字层的 PDF，使用 PyMuPDF 提取文字、题号、页码和坐标框。
2. 根据题干和题库标签计算候选匹配度；匹配只是建议，不会覆盖用户诊断。
3. 每道题保存原 PDF 页码、坐标、解析置信度和题库候选，可从单题工作台打开原页核对。
4. 扫描 PDF 没有文字层时，接口会尝试使用可选 PaddleOCR；未安装时会保留原文件并进入人工确认。

安装数字 PDF 解析依赖：

```bash
python -m pip install -r requirements-ocr.txt
```

PaddleOCR 体积较大，只在扫描件确实需要时安装。题库里已有高度匹配的题目时，系统仍然保留 PDF 页码和位置证据：可以直接把题库题目作为分析基准，跳过重新录入题干，但不会跳过对这次答题过程、得分、错误环节和最终答案的诊断。

## 题库 JSON 示例

```json
[
  {
    "id": "local-001",
    "source": "我的题库",
    "stem": "定积分换元：判断换元变量与上下限",
    "answer": "按新变量同步修改上下限",
    "explanation": "先写换元关系，再检查上下限与符号。",
    "tags": ["定积分", "换元", "上下限联动"],
    "fingerprint": {
      "objects": ["定积分"],
      "method": ["换元积分"],
      "stages": ["切入", "计算"]
    },
    "difficulty": 2
  }
]
```
