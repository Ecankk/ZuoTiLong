# v0.4 网页与 Codex 会话验证

日期：2026-10-22。环境：Windows，本机 Codex CLI 0.163.0，MathLens Python 后端与 React 前端。仅本地运行。

## 已实现

- 点击“连接 Codex”后自动创建一个专用会话，并保存其标识；后续连接恢复同一个会话。沿用本机 Codex 登录，不需要填写模型 API 地址。
- 选试卷/题目后发送文字；指定题目时自动附上原卷对应区域图片。Agent 可通过项目脚本阅读资料、提交诊断与评价。
- 同时只允许一个学习请求。收到完整最终回复且轮次完成后才解锁。进展消息、失败、中断不解除锁定；可重连、核对原轮次、重试原请求。
- 前端禁用输入，后端同时拒绝并发学习写入；请求标识去重。工具授权与补充问题显示在网页中，授权不自动批准。
- 会话保存在个人目录的 `agent-session.db`，与学习数据库分开；记忆与学习证据仍保存在个人资料目录。当前不绑定已有 Desktop 聊天，不应在另一客户端同时向该专用会话输入。

## 验证边界

本次验证针对交互与同步，不等于完整数学诊断质量验收。一次真实讲解的中间公式仍有错误，说明模型讲解需要结合原卷与解析核对，不能将收到最终回复等同于数学正确。

本机 Windows 沙箱阻止了实际工具命令启动；已验证授权请求显示与停止流程，尚未验证用户允许后的完整“读取题库—写回报告”真实工具链。遇到授权请求时，用户可检查命令后决定是否单次允许。系统不会自动提升权限。

真实模型与网页提交测试使用隔离数据；没有向正式画像写入模拟作答。自动测试的 HTTP 拒绝用真实处理器调用验证，不声称完成了真实浏览器并发网络压测。

## 复现

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npm run build
.\.venv\Scripts\python.exe -X utf8 scripts/verify_codex_bridge.py
```

最后一条会调用本机已登录 Codex，创建隔离测试会话并产生实际模型用量；结果写入被 Git 忽略的 `tmp/codex-live-*/validation.json`。正常使用从 `start_mathlens.bat` 启动，在网页连接即可。
