# MathLens 的 Agent 交互设计

2026-10-22 按用户明确的方向调整：MathLens 是 Agent 的可视化数学诊断工作台。学生的主要输入是已完成试卷、围绕某题的补充说明、对话和检验作答。Agent 承担阅读、辨析、选题、评价、讲解；程序承担文件、OCR/裁切、同步、存储与展示。

## 职责边界

| 工作 | 执行者 |
| --- | --- |
| PDF 存档、OCR 草稿、区域裁切、原图链接 | 本地程序，异常交给 Agent 查看 |
| 原卷核对、最早可见错步、竞争原因、针对性提问 | Agent 阅读原卷并与学生讨论 |
| 候选题浏览 | Agent 自选目录/关键词、看题图和旧阅读笔记 |
| 选择哪道题、练哪一步、如何解释 | Agent，根据这次诊断目的判断 |
| 保存实际回答、报告版本、证据和提示情况 | 本地程序 |
| 评价推导、修订画像、安排下一步 | Agent；明确简单答案允许辅助核对 |

不需要全库强制打满指纹，不需要固定相似度排序，也不需要把诊断做成规则引擎。Agent 阅读后留下有来源的笔记，下次可复用。校验题号、区域边界、文件身份和记录引用属于数据可靠性，不决定教学内容。

## 交互循环

1. 上传试卷后展示切分区域与处理进度。
2. Agent 看题干、作答和批改，给出初步观察。学生可以指着某题补充“我这里是这样想的”或纠正识别。
3. Agent 更新判断，浏览已有题库，解释少量候选为什么值得检验；有时只练一题的一步。
4. 学生在网页作答或讨论。Agent 阅读实际表达，解释关键推导，再决定继续追问、换题、给提示或结束该轮。
5. 报告、讨论、选题理由、真实作答、画像与待办持久保存。下一张试卷到来时读取这些证据，检验旧假设。

网页最终需要一个围绕当前题目的讨论区域；支持文字与 LaTeX、原卷区域引用、候选题卡片、提交回答和继续追问。先用这些固定组件，不让模型运行任意 HTML/脚本，也不另做一套无关的聊天产品。

## Agent 指令和长期记忆

- `AGENTS.md`：通用目标、读证据的方法、如何选题、怎样在网页交付、命令和数据约定。
- SQLite 与原图：个人事实的持久依据，保留真实作答与版本；它们不依赖某个 CLI 的上下文窗口。
- `.mathlens/memory/index.md`：简短交接索引，明确事实、待证原因、下一步，链接到报告和作答。不能只靠会话记忆。
- `.mathlens/memory/bank/<bank_id>.json`：Agent 读过题目的注释，包含源图 hash、阅读范围、细分内容、可检验环节和未决问题。
- CLI 会话 ID：会话桥实现后保存，用于继续讨论。重启或换会话仍要读取本地事实；记忆失效不能造成学习记录丢失。

个人内容仅放 `.mathlens/`，不进入公开 AGENTS.md 或 Git。画像中的新结论必须能回溯到原卷、用户明确说明或真实检验作答。标签和自然语言描述可随证据调整，不需要一开始建立完备考纲。

## 网页与 CLI 的连接

v0.4 已实现：报告与检验作答保存在 SQLite；Agent 用 `pending/context/catalog/apply/assess` 读写。网页“与 Codex 讨论”将消息、试卷/题目引用及相关原卷区域图送入一个固定的 Codex 会话，展示增量反馈和工具运行状态。普通交互式 `codex` 终端仍不会自动订阅网页；应用使用独立的官方协议连接。

适配器采用 `codex app-server` 的本地 stdio 协议：本地后端管理进程、初始化连接、创建/恢复会话并接收事件。沿用本机 Codex 登录和默认模型，不在网页重做模型 URL/密钥配置。已用本机 Codex CLI 0.163.0、ChatGPT 登录实际完成两轮验收，中间重启后沿用同一 session 并保留第一轮信息。

适配器必须实现：

- 固定项目工作目录与会话 ID 的持久保存；同一会话按序处理输入，允许中断。
- 真实状态：未连接、等待处理、运行中、等待用户、完成或失败。进程活着不等于正在分析。
- 工具权限/审批请求转交用户，不默认批准，不读取或复制登录令牌。
- 断开后保留消息和产物，重连不重复评价、不重复添加学习事件；网页显示故障而非无限等待。
- 自由解释可以实时显示；正式报告、题目和画像修改仍通过已有写入校验，避免显示一半的报告成为正式数据。

以上功能限一个 MathLens 专用会话。每轮反馈完成前，网页输入禁用，后端对其他学习写入返回 409；进展文字和失败不会解锁。停止、断线或异常时保留原请求，重连核对状态后可重试。已有 CLI/Desktop 开发聊天不会被自动接管，也不支持多会话切换。其他 CLI 暂不接入。

## 接入验收

测试必须覆盖：网页提交一条带题目引用的消息、Agent 从原图解释并写回、学生追问沿用会话、退出重启后恢复本地背景、提示后的作答不被标成独立掌握、拒绝审批/连接失败可见且不丢记录。模拟作答只进入隔离库。

自动测试覆盖并发提交、重复请求、最终反馈门槛、旧事件隔离、断线恢复、显式授权和后端写锁；真实连接测试位于 `scripts/verify_codex_bridge.py`，只使用独立测试目录。前端仍用每秒读取本地状态的方式展示 Codex 事件；不依赖远端网页服务。
