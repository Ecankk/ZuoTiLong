# 题库维护流程

本文规定通用题库从接入到可练的固定流程、每一步的关卡和产物位置。命令与字段见[题源接口](bank-source-interface.md)，标注任务契约见[Agent协议](agent-workflow.md)，题源状态见[题源目录](question-sources.md)。本文不记录具体批次结果，批次状态只写在本机TODO。

## 角色

| 角色 | 负责 | 不做 |
| --- | --- | --- |
| 标注会话 | 备份、导入、标注、受控修订、勘误预演与确认、目录维护任务；唯一写主通用库的会话 | 自行决定勘误内容是否成立、跳过预演直接确认 |
| 调研子代理（只读） | 找第二来源、逐题验算、起草勘误、TikZ重绘题图 | 写题库、仓库或应用数据 |
| 协调会话 | 分类、审核草稿与预演报告、授权确认、向用户汇报 | 直接写题库 |
| 用户 | 只处理需要原书或个人判断的事项，以及规则变更 | 逐题例行核对 |

模型：标注、复核、修订和起草勘误使用判断档 GPT-6.1-Sol（xhigh），只在题库维护工作区设置，不改用户学习工作区。

## 流程

1. **接入**：在题源目录登记版本和许可，写或复用适配器，转出标准 JSONL。新书或新分篇单独成题集，不与已有题集混合（例如测试卷独立为 zhangyu-1000-tests）。
2. **导入**：备份 → `--dry-run` → 协调会话核对 added/updated/conflicts → 用预演的 plan_sha256 执行 `--confirm`。
3. **标注**：每批 1～8 题，交付 ready / needs_review / needs_catalog 三种状态。缺目录走 maintain_catalog 补原子后重标该题。
4. **待核分流**：协调会话把 needs_review 题分成四类：
   - **A 有依据**：第二来源中有同题，或能独立推导出原文应有的样子 → 写勘误。
   - **B 数学自洽补全**：解析笔误、缺常规题设、题干与解析不一致但答案相同 → 写勘误。reason 以“【未核原书，按数学自洽补充】”开头，改后答案须与答案栏一致。
   - **C 无法确定**：缺原图且推不出，或原文的指数、分量、目标不能唯一确定 → 保持待核，不进入练习；图能唯一推出时可重绘后升为B。
   - **真题**：题面是原卷图片，不改题面；只用受控修订补 answer_check.note 后放行。
   起草由调研子代理完成，输出逐题计划（分类、改动、答案是否一致）和勘误草稿。每条 find 须在当前文本中唯一命中。
5. **勘误**：勘误文件按“题源 × 题集”各维护一份累积文件，放在 `<数据目录>/curation/errata/<题源>-<题集>.json`；新批次追加到末尾。导入只套用本次传入的文件，不读库中的历史勘误，所以每次都要整份传入，否则早先的勘误会被撤销。流程：备份 → 预演 → 协调会话核对 → 确认 → 失效的题重标。
6. **补图**：属于核对阶段的补救，由协调会话决定，不交给用户。图能从题面和解析唯一推出时，调研子代理在 WSL 发行版 `LaTaX` 里用 TikZ 重绘，图内角落注明“按题意重绘”，另附每个元素的依据。补图文件也按“题源 × 题集”累积，和勘误一样走预演、核对、确认，不改动来源原始记录。入库入口实现前（B27），图只作为离线材料。
7. **收尾**：在TODO记一行，内容包括题集、ready / needs_review 数、仍待核的原因类别、备份文件名。不另写验收报告。

## 关卡（协调会话必须核对后才放行）

| 关卡 | 核对项 |
| --- | --- |
| 导入或勘误预演 | plan_sha256；added / updated / unchanged 数；更新是否只落在目标题；identity / collection 冲突为0；find 无未命中；失效标注数等于更新题数 |
| 勘误草稿 | 抽查第二来源证据；B类答案与答案栏一致；没有用答案反推题面；C类没有被硬改 |
| 受控修订 | allowed_fields 最小；resolve_review 只针对 needs_review 题；回执和备份齐全 |
| 重标结果 | ready / needs_review 分布；新出现的待核原因再走一次分流 |

以下情况停下来问用户：需要原书才能定的题、改动题集划分或显示范围、修改以上规则。其余由协调会话决定，事后汇报。

## 人工核对页（可选）

`scripts/review_sheet.py` 能生成一题一卡的只读核对页，用法见[题源接口](bank-source-interface.md)。它适合用户手上有原书时使用，不作为默认关卡。

## 文件位置

| 产物 | 位置 |
| --- | --- |
| 累积勘误 | `<数据目录>/curation/errata/` |
| 预演与应用报告、调研草稿、重绘题图 | 系统 TEMP 下的私有目录；需要长期保留的才移到 `<数据目录>/curation/` |
| 备份 | `<数据目录>/backups/`（导入入口自动生成） |

题库正文、勘误和图片不进入版本库。
