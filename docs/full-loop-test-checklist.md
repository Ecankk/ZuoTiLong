# MathLens 首次完整回归测试

这份清单用于在本地从头验证一轮真实试卷。它不把“页面能打开”当成教学质量通过；每一项都应记录观察结果、原卷题号和是否需要 Agent 追问。测试前先备份 `.mathlens/`，不要删除个人数据库来排错。

## 测试前检查

- [ ] 使用 `setup_mathlens.bat` 创建或确认 Python 3.11/3.12 虚拟环境；Codex CLI 已登录。
- [ ] 双击 `start_mathlens.bat`，以启动器自动打开的地址为准；不要假定端口一定是 4173。页面和 `/api/health` 都应返回成功。
- [ ] 设置中选择本次备考类别；确认是否隐藏同类别针对性检验题，并按需要填写预留整卷。题库直接浏览不受此隐藏开关影响。
- [ ] 确认 `.mathlens/` 和 `tmp/` 没有被 Git 跟踪；真实试卷、照片和画像不进入提交。

## A. 试卷导入和切分

1. 上传一份已完成 PDF，填写可识别的名称和日期。
2. 检查页数、每题区域、题号、分值、原图和 OCR 草稿。至少抽查选择题、填空题、解答题、跨页题和带小问题。
3. 对有红笔、黑笔、涂改、图形或手写公式的页面，确认原图仍完整，OCR 只用于定位，不能替代图像证据。
4. 若出现警告、缺页或无法定位，记录具体页码和问题；当前上传/OCR 为同步任务，刷新和断线恢复仍是已知缺口，不要把“页数非零”当切分全部成功。

## B. Agent 诊断

1. 右侧点击“连接 Codex”，确认使用一个本机专用会话；不要同时在另一个 CLI/Desktop 窗口向该会话输入。
2. 发送诊断请求，确认发送时的试卷、题号、缩略图和页面上下文与主区一致。发送中应禁止新的学习输入，完整最终反馈后才解锁。
3. 检查 Agent 是否区分：题目要求、最早可见错误步骤、已经完成的正确步骤、批改痕迹、尚待验证的竞争原因。空白不能直接推断为不会或心态问题。
4. 检查报告是否覆盖全卷题号、每题有区域、指纹、原因假设和限制说明；如果只写了部分题，记录为阻塞项，不接受“诊断已完成”。当前 `expected_count` 缺失仍可能绕过后端校验，这是 R01。

## C. 题库检索和检验保护

1. 让 Agent 只从当前本地资料范围内选择少量题，并说明每题针对原卷哪条原因假设、只检验哪个环节、正确/错误分别说明什么。
2. 在本地题库页测试数一、数二、数三直接浏览。切换备考类别和隐藏开关，再从试卷检验卡测试：只有当前类别且开启隐藏时先显示年份/题号，确认后才返回题干；其他类别直接显示。
3. 确认前不要通过图片 URL、解析 URL、刷新、Agent 附件或旧链接绕过隐藏。预留整卷不得被 Agent 选入，但用户可以自主浏览。
4. 查看题干和解析各一次，检查曝光记录分开保存；浏览不增加作答成功，也不解除下一次同类别候选确认。

## D. 真实作答和评价

1. 对一个明确的检验环节先提交文字作答，再对另一个检验只上传手写照片；照片可不填文字。检查原图方向、顺序、大小限制和题目绑定。
2. 提交后确认输入锁定；只有 Agent 完整反馈结束才能进行下一轮。失败、断线和中断时应能重试原轮次，或确认放弃并保留输入。
3. 让 Agent 读取实际作答照片并通过 `assess` 写回 `true`、`false` 或 `null`。`null` 必须显示为证据不足，不能计入成功/失败。
4. 测试重复点击和刷新：同一请求不应重复建作答或画像事件。
5. **独立证据专项检查：**先独立提交作答，再查看解析，然后补充完整推导。当前 R02 尚未修复，补充可能仍被统计为独立成功；在此项修复前不要用画像中的独立成功次数作学习结论。
6. 测试“对评价提出异议”和“请 Agent 调整检验”，确认保留旧评价/旧检验及原因；这两个入口不等于已经完成新的独立复测。

## E. 报告和画像

- [ ] 原卷总分只有在逐题分值有依据时显示；未知值应保持待核定。
- [ ] 待作答、待评价、待补图、待复核分别可见。
- [ ] 画像明确区分原卷错误、检验失败、检验成功、看过解析后的提示证据和未决原因。
- [ ] 新卷导入后旧卷、旧作答、曝光和题库阅读笔记仍可追溯；单卷结论不能写成长期稳定掌握或心态结论。

## F. 恢复与隐私

- [ ] 创建备份；在隔离目录恢复后能打开原卷、图片、报告和草稿。当前恢复后的 Agent session 图片路径和恢复 UI 仍是 R06，不能默认迁机可用。
- [ ] 清理无引用照片会移动到可恢复目录，不直接永久删除；确认没有误删仍在会话草稿或检验中的图片。
- [ ] 关闭服务后重新启动，页面地址从 `.mathlens/server.json` 读取；检查日志中不含试卷正文、照片或 Codex 私密认证信息。

## 当前测试结论口径

已通过：51 项 Python 回归、6 项 KaTeX/公式测试、TypeScript/Vite 构建；真实 Codex 工具链在隔离合成材料中完成过诊断、检索、读图、报告写回、评价和记忆写回；本地页面与健康接口可访问。

仍需在真实材料上确认：复杂手写和红笔批改、跨页/多栏 PDF、题库候选的数学正确性、错因假设的支持/排除、R01 报告完整性、R02 独立证据、R03 不确定评价复核、R04 单题原因修订与独立复测、R06 恢复路径、R07 上传/OCR 失败恢复。没有完成这些检查前，不把画像统计或“分数提升”当作产品验收结论。

发现问题时记录：试卷/题号、页面或检验 ID、看到的原图、Agent 回复、是否写入画像、复现步骤和时间。不要直接编辑 SQLite；优先复制数据目录或使用隔离浏览器夹具复现。
