调研日期：2026-10-22。已联网搜索项目原始页面，并将两个优先候选克隆到 `F:/kaoyan/references`。本轮核验的是数据结构、资源完整性与少量视觉样本，未完成检索命中率、数学正确率或手写诊断准确率评测。

## 对 math-question-bank 的判断修正

它是有配套资料时使用的本地题库浏览、练习和维护工具。其 README 明确 PDF、页面图和裁剪图被排除出 Git；因此不能由“克隆中缺图”推定作者的完整本地系统不可用，也不能推定 2,900 道题全部错误。

但仅靠公开克隆，确实无法获得完整答案和题图，而且现有资料偏数二。对我们的目标，它适合作为可选练习题源，不宜承担数学一主库，更不能替代整卷定位、作答读取和错因诊断。模板绑定的提取脚本也不等于任意试卷自动切题。

## 适合本项目的识题与诊断流程

1. 已知真题：先识别卷种、年份、题号，用本地标准题检索核对。原卷题干只需足够辨认和定位，避免每次重复完整转录。
2. 未知模拟题：用印刷题干区域生成文字、公式、图形候选特征，召回多个近邻，再核对条件、参数、选项及所问目标；题型相近不代表同一道题。
3. 同步保留学生作答及批改原图。为检索准备的清洁题干副本与用于诊断的原始作答分开，不能把手写擦除后丢掉诊断证据。
4. 同题命中后取参考解答，对比学生关键步骤，定位最早的可见错误。支持多种合法解法，不能把与参考解答顺序不同直接视为错误。
5. 区分“已经观察到的错步”和“尚待检验的原因”。再从题库选择少量能区分原因的题目或题目中的一个环节。
6. 未命中题库时仍保留原图进行诊断；模型推导的参考解不冒充已核验答案，后续可补证据。不能因没有检索到原题就要求用户手工录入整题。

图片/公式/文字的识别与索引由系统批处理、缓存、增量更新。数据源的路径修复、同题对齐和格式规范化属于开发和后台处理成本，不应转为学生逐题校对任务。

先用这 386 道数学一真题建立可验证的小型基准：原题命中、参数变式拒绝误认、图文完整、作答区域定位、失败原因明确。题库再大也不能跳过这些验证。对应的知识点和错因指纹随后按诊断需要补充，不要求一次性人工标完全部资料。
