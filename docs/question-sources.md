## 导入和质量记录约定

1. 题源身份保留 `source_id/revision/source_uid`；书籍另保留书名、版次、篇章、组别、原题号、页码/区域、数学习题适用范围。未知值明确为空，不编造年份或 B组映射。
2. 原图/原始电子文本与规范化展示分开保存；记录文件 SHA256。文件身份、题目语义指纹、学生错因和掌握证据是不同数据，不能用一个散列代替。
3. 对候选分别记录题干完整性、必要插图、答案和解析的可获得性，以及 Agent 核对过的具体步骤。数学核验按本次选中题开展，不要求学生校对整库。
4. Agent 阅读实际题目与相关解析，确认目标环节、前置条件和干扰因素，说明为何可区分原题的竞争错因。分类只辅助导航，不按字符串/向量分数自动作教学决定。
5. 重复来源保留映射和原件；条件、题号、结论冲突进入待核对状态，不能无条件合并。综合来源中的真题须保留原年份/类别，便于执行用户设置和记录曝光。
6. 初次接入每个新格式，先用少量题验证“原题号与公式完整 → Agent读题选题 → 网页正确展示 → 真实作答评价”。通过后扩大导入。不能把题数、解析字段存在或 KaTeX 通过当数学质量指标。
7. 应用仓库维护适配器、来源目录和许可说明；第三方教材正文、PDF、图片放用户本地资料目录，不随公开代码分发。来源目录中的链接是研究记录，不是再分发授权认定。
