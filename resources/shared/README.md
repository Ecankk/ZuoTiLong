# 首版通用资料

这些文件随源码提供，用于空资料库初始化。它们不是维护者运行数据库的副本。

| 文件 | 项目提供的内容 | 不包含 |
| --- | --- | --- |
| [catalog.json](catalog.json) | 1001个发布节点，其中963个原子；稳定ID、定义/条件、层级、别名、重定向及来源索引 | 来源原文、扫描页、个人学习状态、会话或本机路径 |
| [question-index.json](question-index.json) | 1152条就绪标注索引；题目材料散列、原子/环节关联、定义依赖和通用审核出处散列 | 题干、答案、完整解法、题图、个人作答与模型执行日志 |

数量是本资料包的固定快照，不是每个原子都有题、全库数学零错误或所有记录互不重复的承诺。当前5条有参考争议的记录及1条与固定S01题干图不匹配的本机变体未进入共享索引；实际可导入数量以本地预览为准。

## 用户还需要准备

1. 可用的本机Codex CLI和账号登录。
2. S01题目材料：[lx-ruc/kaoyanshuxue](https://github.com/lx-ruc/kaoyanshuxue/tree/196dc9d2d8271978a030a3721a828c8723cd3864)，固定版本`196dc9d2d8271978a030a3721a828c8723cd3864`，数学一/二/三2009–2025。自行取得题干、答案和解析；本项目不分发原图。修改过的题图可能无法匹配本索引，不能改散列绕过。
3. 本人的已做试卷PDF，以及后续练习的手写照片或文字。

## 导入顺序

按[配置教程](../../docs/setup.md#3-配置题库考点和标注)先导入本地题库，再在设置中预览、确认导入catalog.json，最后预览、确认导入question-index.json。进入“考点树→全部题库”核对关联；新工作区不应因此产生个人完成记录。

包内sha256是应用校验的内容散列，不是JSON文件字节散列；导入时以预览显示的包散列核对：

```text
catalog:        02c497e9a1166de365353b8a73443f323aaf7f1bf9d3d48c56e17f3887524f37
question-index: 4ff61daeecd12dce11e8c5585696036e383fcbc42f0ba5afcb00501fefe932c4
```
